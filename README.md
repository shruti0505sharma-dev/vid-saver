# Vid Saver

A video and audio downloader application built with Flask (Python) and React (Vite), powered by yt-dlp and ffmpeg.

## Features
- Download videos from supported platforms (YouTube, Instagram)
- Multiple quality and format options (MP4, MP3/M4A)
- Real-time download progress tracking
- Docker-ready deployment configuration

## Getting Started

### Backend
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

### Frontend
```bash
cd frontend
npm install
npm run build
```
